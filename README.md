# 风机偏航对中台

现场技师登记机组编号、偏航误差（度）并**点选功率档**；后台 worker 用数据库行锁认领待处理记录，在同一事务内读取该档现行闭区间并写入单据快照，按**认领快照的那一档上下限**判定「合格」或「偏航超差」。偏航合格判定按功率档分带：微风档、大功率档各有自己的闭区间，技师可改档（留有改档流水）。前端为 Lit 组件 + Vite，接口为 Quart + Hypercorn。

| 用户 | 密码 | 权限 |

## 功率档合格带台

顶栏「功率档合格带」打开专页，三区并列：

- **上区**：各档现行闭区间上下限（微风档、大功率档）。技师可改档，观察员只读。
- **中区**：改档流水（旧/新闭区间、改档人、时间）。
- **下区**：认领快照说明。

关键规则：

1. 新单**必须点选功率档**，漏选整单退回（前端拦截 + 后端 400，缺一不可）。
2. 判定吃该档**现行**闭区间：worker 认领 pending 单据的同一事务内，锁定档位行、读取上下限写入单据 `snap_lower_deg/snap_upper_deg/claimed_at` 快照。
3. **已认领单据沿用认领当时的快照**：之后改档不改变其结论，只影响改档后新认领的单据。
4. 档位表入库值是唯一数据源：新单下拉点选项与上区上下限均取自 `GET /api/gears`，前后端同源，少一环即不过。

## 启动

```bash
docker compose up --build
```

健康检查：`GET http://localhost:8199/api/health` → `{"status":"ok","service":"yaw-align-log"}`。

## 验收

1. 种子数据：机组 W01（微风档）误差 0.4° 结论「合格」；机组 W07（大功率档）误差 3.2° 结论「偏航超差」。
2. technician 提交新记录必须选功率档；不选时整单被退回；选后列表先显示「待认领」，数秒内 worker 处理后按该档快照给出结论。
3. 把**微风档上限改成 1.0°**，再报微风档误差 **1.2°**，应判「偏航超差」；把上限**改回 1.5°** 后，同样 1.2° 应判「合格」。改档前后已认领单据结论不变（中区流水可查）。
4. observer 登录：无报送表单、上区无改档入口，仅可浏览档位表与改档流水。

## 接口

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | `/api/gears` | 登录 | 各档现行闭区间（页面下拉与上区唯一数据源） |
| PUT | `/api/gears/<gear_key>` | 技师 | 改档，校验下限≤上限并追加流水 |
| GET | `/api/gear-changes` | 登录 | 改档流水 |
| GET | `/api/logs` | 登录 | 记录列表（含档位与认领快照区间） |
| POST | `/api/logs` | 技师 | 报送，必传 `gear_key`，漏选 400 整单退回 |

## 技术栈

- 后端：Quart、psycopg、`worker.py`（`FOR UPDATE SKIP LOCKED`，认领同事务写快照）、Hypercorn
- 前端：Lit、TypeScript、Vite；生产镜像内 nginx 反代 `/api`
- 镜像源：DaoCloud 基础镜像、清华 PyPI、npmmirror npm
